# Evidencia visual de autoservicio de Citas

19 de octubre de 2026. App local en 3118, Postgres desechable y cuentas/contactos sintéticos.
Compilación Webpack con fuentes simuladas locales. Se conservó el tema existente del navegador.

- `busqueda-contacto-escritorio.png`: búsqueda por teléfono encuentra el contacto que está después de 505 registros; conserva la selección y muestra el especialista fijo.
- `agenda-propia-escritorio.png`: acceso limitado a Ana, selector bloqueado y citas de su agenda.
- `acceso-por-especialista-escritorio.png`: Configuración → Usuarios, acceso de Ana limitado a su especialista y guardado con admin.
- `reprogramar-horarios-movil.png`: selección de día/hora y confirmación del nuevo horario (página completa).
- `reprogramacion-confirmada-movil.png`: cita guardada en el horario nuevo; se comprobó persistencia recargando el mismo enlace.

Escritorio: tamaño disponible del panel del navegador, aproximadamente 870×668.
Móvil: 390×844. El tamaño temporal se restableció después de verificar.
El navegador de pruebas se cerró; no se enviaron mensajes reales.
