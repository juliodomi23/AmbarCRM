# Verificación visual de entrega de Citas

19 de octubre de 2026. Capturas de la compilación local verificada, con datos
sintéticos y fuentes simuladas. Se conserva el tema existente de la aplicación.
No se enviaron mensajes externos. El navegador de prueba se cerró y se restableció
el tamaño de ventana después de comprobar estos recorridos.

- `asistencia-confirmada-movil.png` (390 × 844): el paciente confirma desde el enlace
  de una cita creada en recepción; se muestra el estado Confirmada y el horario en
  America/Tijuana.
- `enlace-recepcion-escritorio.png` (1280 × 720): recepción obtiene el enlace personal
  desde el detalle y comprueba la respuesta «Enlace copiado».

  a las 10:00 en America/Tijuana, aun con doce citas posteriores en el expediente.
